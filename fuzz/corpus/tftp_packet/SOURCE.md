# Seed origin: `tftp_packet`

Every seed here is generated by our own code from the `usgp_tftp`
encoders (`encode_request`, `encode_ack`, `encode_data`, `encode_error`,
`encode_oack`). None comes from packet captures, logs, images or any
deployment of another product (fuzz/README.md, seed origin rule).

The first octet selects the path: even = one packet for `parse` and the
round trip; odd = a transfer script. The script format is defined in
`fuzz_targets/tftp_packet.rs`.

Regenerate (from the repository root):

```sh
cargo run -p usgp-tftp --example gen_fuzz_seeds -- fuzz/corpus/tftp_packet
(cd fuzz && cargo run --example gen_seeds -- corpus)
```

| Seed | Generator | Content |
|------|-----------|---------|
| `rrq-plain.bin` | `crates/usgp-tftp/examples/gen_fuzz_seeds.rs` | `0x00` + RRQ `usgp-test-payload.efi`, `octet` |
| `rrq-options.bin` | same | `0x00` + RRQ with `blksize=1468`, `tsize=0` |
| `rrq-timeout-windowsize.bin` | same | `0x00` + RRQ `a/b.efi`, `OCTET`, `timeout=5`, `windowsize=4` |
| `wrq.bin` | same | `0x00` + WRQ `x`, `octet` |
| `data.bin` | same | `0x00` + DATA 1 `payload` |
| `ack0.bin`, `ack1.bin` | same | `0x00` + ACK 0 / ACK 1 |
| `error8.bin` | same | `0x00` + ERROR 8 `rejected` |
| `oack.bin` | same | `0x00` + OACK `blksize=1468`, `tsize=5632` |
| `transfer-rrq-options.bin` | same | `0x01` + RRQ with options. Written before the script format existed, so the target reads the RRQ octets as the script header; kept as a mutation seed |
| `wu8-script-plain-complete.bin` | `fuzz/examples/gen_seeds.rs` | script: 2000-octet file, plain RRQ, ACK 1..4 to completion |
| `wu8-script-oack-dup-ack.bin` | same | script: 1500 octets, RRQ `blksize=512`, `tsize=0`; OACK, ACK 0, duplicate ACKs, completion |
| `wu8-script-timeouts.bin` | same | script: 1000 octets; four timer expiries (handshake retry cap) |
| `wu8-script-early-future-raw.bin` | same | script: 700 octets; early timer, future ACK, ACK 9, raw ACK 1 |
| `wu8-script-client-error.bin` | same | script: 100 octets, RRQ with options; client ERROR 8 |
| `wu8-script-data-mismatch.bin` | same | script: 100 octets; ACK 1 then a wrong file slice |
| `wu8-script-blksize-8.bin` | same | script: 600 octets, RRQ `blksize=8`; 80 ACKs of the outstanding block |
| `wu8-script-exact-multiple.bin` | same | script: 1024 octets (empty final block), three ACKs |
| `wu8-script-too-large.bin` | same | script: `max_file_size` = length - 1 (refused) |
| `wu8-script-netascii.bin` | same | script: RRQ in `netascii` mode (refused) |
| `wu8-script-max-duration-0.bin` | same | script: `max_duration` 0; first timer ends the transfer |

Config octets in every `wu8-script-*` seed unless stated: A = `0x35`
(`max_retries` 5, `handshake_retries` 2, block-size cap 1468); B = `0xf0`
(`max_duration` 120 s, default `max_file_size`). See
`fuzz/examples/gen_seeds.rs`.
