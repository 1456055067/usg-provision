## Incident CR-001 (BLOCKER, round 1): quoted source term in a spec

- Location: `specs/targeting.md:141` (REQ-TGT-007 Source line, round-1
  text).
- What: a two-word term from the vendor release note (SRC-004), in
  quotation marks, describing a configurable product behaviour. It is
  probably the vendor's name for a setting or feature. The term itself is
  not repeated in this record.
- Why it is contamination: it put a vendor label, shown as a quotation, in
  a clean-side spec, where clean-side agents could carry it into config
  keys or UI text. It also contradicted the spec report's statement that no
  vendor terms reached `specs/`.
- Did it reach the clean side: the M3 specs were DRAFT and awaiting audit.
  No clean-side plan, code or commit from this run used them. The working
  tree at re-audit has no other occurrence of the term in `specs/` or in
  code.
- Remediation: the researcher replaced the quotation with a generic
  description ("an operator-configurable mode needing no input at the
  device exists; not publicly defined"). The fix was verified in the
  re-audit (`specs/targeting.md` REQ-TGT-007, `specs/INDEX.md`
  Unconfirmed).
- Status: closed 2026-10-28.
