# Seed origin: `agent_package_manifest`

Every seed here is generated by our own code in `examples/gen_seeds_m4.rs`
(function `agent_manifest_seeds`): `agent.json` text written in the generator,
checked with `AgentPackageManifestV1::from_json` (accepted unless stated). None
comes from captured traffic, a log, an image, a driver package, tool output or
any deployment of another product (fuzz/README.md, seed origin rule).

Regenerate (from `fuzz/`):

```sh
cargo run --example gen_seeds_m4 -- corpus
```

| Seed | Content |
|------|---------|
| `wu12-msi.bin` | installer only, `.MSI` |
| `wu12-exe-full.bin` | every key |
| `wu12-bat-refused.bin` | `.bat` installer (refused) |
| `wu12-unknown-key.bin` | an unknown key (refused) |
