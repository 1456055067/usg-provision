# Seed origin: `zip_archive`

Every seed here is generated by our own code in `examples/gen_seeds_m4.rs`
(function `zip_seeds`): ZIP files written by `usgp-wincfg`'s
`archive::testkit::ZipBuilder`, with DEFLATE data from its
`deflate_stored`/`deflate_fixed` and from
`miniz_oxide::deflate::compress_to_vec`; the INF text is written in the
generator (plan section 1.5). Accepted archives are checked with
`validate_archive_mode`. None comes from captured traffic, a log, an image, a
driver package, tool output or any deployment of another product
(fuzz/README.md, seed origin rule).

Regenerate (from `fuzz/`):

```sh
cargo run --example gen_seeds_m4 -- corpus
```

| Seed | Content |
|------|---------|
| `wu12-driver-stored.bin` | stored driver package: folder, INF, catalog, driver file |
| `wu12-driver-deflate.bin` | Deflate entries (dynamic, fixed with a match, stored blocks) |
| `wu12-zip64-descriptor.bin` | Zip64 extra fields and end records, a data descriptor |
| `wu12-agent-package.bin` | `agent.json` and an `.msi` placeholder (plain mode) |
| `wu12-traversal.bin` | `../evil.inf` (refused, bad name) |
| `wu12-bad-crc.bin` | wrong CRC-32 (refused) |
