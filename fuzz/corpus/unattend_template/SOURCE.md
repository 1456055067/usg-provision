# Seed origin: `unattend_template`

Every seed here is generated by our own code in `examples/gen_seeds_m4.rs`
(function `unattend_seeds`): answer-file templates written in the generator in
the shape of plan section 1.6 and `specs/standards/unattend.md` (element names
only; no setting values from any real file), each checked by `Template::parse`
(accepted unless stated). None comes from captured traffic, a log, an image, a
driver package, tool output or any deployment of another product
(fuzz/README.md, seed origin rule).

Regenerate (from `fuzz/`):

```sh
cargo run --example gen_seeds_m4 -- corpus
```

| Seed | Content |
|------|---------|
| `wu12-good.bin` | computer name, time zone, domain and OU references |
| `wu12-plain.bin` | no references; an escaped attribute and a comment |
| `wu12-attr-ref.bin` | a `device.` reference in an attribute |
| `wu12-secret-setting.bin` | an `AdministratorPassword` setting (lint finding) |
| `wu12-ref-in-command.bin` | a reference inside `RunSynchronous` (lint finding) |
| `wu12-doctype.bin` | DOCTYPE with an entity (refused) |
| `wu12-bad-ref.bin` | `{{bad name}}` (refused) |
| `wu12-wrong-root.bin` | another root element (refused) |
