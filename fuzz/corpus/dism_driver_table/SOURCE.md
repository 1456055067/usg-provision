# Seed origin: `dism_driver_table`

Every seed here is generated by our own code in `examples/gen_seeds_m4.rs`
(function `dism_seeds`): list-format driver listings written in the generator
with the seven labels of `specs/standards/offline-drivers.md` §7.3 and made-up
values (`Example Corp`), checked with `parse_driver_table` (accepted unless
stated). No real tool output. None comes from captured traffic, a log, an image,
a driver package, tool output or any deployment of another product
(fuzz/README.md, seed origin rule).

Regenerate (from `fuzz/`):

```sh
cargo run --example gen_seeds_m4 -- corpus
```

| Seed | Content |
|------|---------|
| `wu12-two-drivers.bin` | banner, two driver blocks, trailer |
| `wu12-two-drivers-crlf.bin` | the same with CRLF |
| `wu12-missing-version.bin` | no `Version` (refused) |
| `wu12-duplicate-field.bin` | `Inbox` twice (refused) |
| `wu12-bad-inbox.bin` | `Inbox : maybe` (refused) |
