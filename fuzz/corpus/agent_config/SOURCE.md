# Seed origin: `agent_config`

Every seed here is generated by our own code: `usgp-proto`
`AgentConfigFile` values written with `to_toml` (the module documentation
example and two variants), and server URLs written in the generator. The
host names are `example` names (RFC 2606) and private addresses; none
comes from a deployment of any product (fuzz/README.md, seed origin rule).

Octet 0 selects: 0, the file; 1, a URL.

Regenerate (from `fuzz/`; function `agent_config_seeds`):

```sh
cargo run --example gen_seeds_m3 -- corpus
```

| Seed | Selector | Content |
|------|----------|---------|
| `wu14-agent-full.bin` | 0 | every key, the module documentation example |
| `wu14-agent-minimal.bin` | 0 | IPv4 server, no optional keys |
