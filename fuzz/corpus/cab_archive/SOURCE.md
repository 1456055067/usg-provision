# Seed origin: `cab_archive`

Every seed here is generated by our own code in `examples/gen_seeds_m4.rs`
(function `cab_seeds`): cabinets written by `usgp-wincfg`'s
`archive::testkit::CabBuilder` (MSZIP blocks are its stored DEFLATE blocks); the
INF text is written in the generator. Accepted cabinets are checked with
`validate_archive_mode`. None comes from captured traffic, a log, an image, a
driver package, tool output or any deployment of another product
(fuzz/README.md, seed origin rule).

The target forces octets 0 to 3 to `MSCF`; every seed already starts so.

Regenerate (from `fuzz/`):

```sh
cargo run --example gen_seeds_m4 -- corpus
```

| Seed | Content |
|------|---------|
| `wu12-cab-none.bin` | uncompressed folder, driver package |
| `wu12-cab-mszip.bin` | MSZIP with data-block checksums |
| `wu12-cab-reserve.bin` | reserve fields in header, folder and data blocks |
| `wu12-cab-two-blocks.bin` | a 40,000-octet file across two data blocks |
| `wu12-cab-type-3.bin` | compression type 3 (refused) |
