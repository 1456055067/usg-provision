# Seed origin: `winapi_reparse`

Every seed here is generated by our own code: `REPARSE_DATA_BUFFER`
values assembled in the generator from the layout of
`specs/standards/reparse-and-security-descriptors.md` (topic 24 §2 to §5),
with made-up names on drive `T:`. None comes from a WIM, a file system, a
Windows installation or any product or deployment (fuzz/README.md, seed
origin rule). The whole input is the buffer.

Regenerate (from `fuzz/`; function `reparse_seeds`):

```sh
cargo run --example gen_seeds_m3 -- <scratch>
cp <scratch>/winapi_reparse/*.bin corpus/winapi_reparse/
```
