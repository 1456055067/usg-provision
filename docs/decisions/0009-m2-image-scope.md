# 0009: M2 Image Scope — Windows 11 Enterprise x64

- Status: Accepted (owner, 2026-10-26)
- Date: 2026-10-26
- Decider: project owner
- Basis: project design; not described product behaviour

## Decision

In M2 the product accepts Windows 11 Enterprise x64 images as package
content. Other editions, architectures and Windows 10 images are refused
with a clear, audited error. Wider support is a later decision.
