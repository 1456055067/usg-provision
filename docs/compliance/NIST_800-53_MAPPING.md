# NIST SP 800-53 Rev 5 control mapping

Status as of milestone M1 (network boot, 2026-10-26; CI evidence added
2026-10-27). Statuses are backed by code and passing gates only; nothing
here is a claim of control satisfaction for the ATO. Values: Not
implemented, Planned, Partial, Implemented.

M1 evidence limits that apply to every row below:

- QA's tests ran on a macOS development host, where the relay's socket
  layer (`SO_BINDTODEVICE`, Linux only) does not run; those results are
  in-process with in-memory sockets.
- Live evidence comes from GitHub Actions run 40438138720 (commit 70e3c1f,
  2026-10-27, written "CI 40438138720" below): every job succeeded, and
  boot smoke S1 to S8 passed on Linux with KVM and OVMF firmware, relay as
  uid 65534 (`pass=9 fail=0 not_run=0`). It is one run in one lab
  topology. The first CI run (40434148508) failed on harness defects and
  is superseded.
- QA's final pass (2026-10-26) confirmed every fix-round 2 and 3 test by
  name. The one Linux-only test (`config_rejected_carries_host_node_name`)
  was not run by QA; the CI `gates` job ran the workspace tests on Linux
  and succeeded, but its per-test log has not been reviewed.
- Test names are listed in `docs/compliance/TEST_EVIDENCE.md` and
  `docs/compliance/SPEC_TRACEABILITY.md`.
