# Seed origin: `device_session_msgs`

Every seed here is generated by our own code: JSON bodies written in the
generator in the wire shape of the M3 plan §3.1 (the same shapes as the
`usgp-proto` unit tests), each checked by the generator with
`parse_request` and `MAX_DEVICE_JSON_BYTES` (accepted unless stated),
`usgp-proto` types serialized with `serde_json` (the disk descriptor,
the confirm response), and text values written in the generator. The
envelope signatures are 103 octets of `0x30`, not real signatures (the
target only parses). None comes from captured traffic, a log or any
deployment of another product (fuzz/README.md, seed origin rule). The
session token and codes are made-up values, not secrets of any system.

Octet 0 selects the body type (see `fuzz_targets/device_session_msgs.rs`).

Regenerate (from `fuzz/`; function `device_seeds`):

```sh
cargo run --example gen_seeds_m3 -- corpus
```
