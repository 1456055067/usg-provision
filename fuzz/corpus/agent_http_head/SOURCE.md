# Seed origin: `agent_http_head`

Every seed here is generated by our own code: HTTP/1.1 response heads and
`Content-Length` values written as literals in the generator, in the shape
RFC 9112 §2 and §6.3 describe. None comes from captured traffic, logs or
any server of any product or deployment (fuzz/README.md, seed origin
rule).

Octet 0 selects: 0, a response head as received; 1, the value of the one
`Content-Length` header in an otherwise valid head
(`fuzz_targets/agent_http_head.rs`).

Regenerate (from `fuzz/`; function `http_head_seeds`):

```sh
cargo run --example gen_seeds_m3 -- <scratch>
cp <scratch>/agent_http_head/*.bin corpus/agent_http_head/
```
