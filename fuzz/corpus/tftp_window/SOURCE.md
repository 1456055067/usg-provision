# Seed origin: `tftp_window`

Every seed here is generated by our own code: RRQs from
`usgp_tftp::encode_request` (RFC 1350 §5 with the RFC 2347, 2348, 2349
and 7440 options) inside the script format of
`fuzz_targets/tftp_window.rs`. None comes from a packet capture, a log or
any deployment of another product (fuzz/README.md, seed origin rule).

Unless stated, `max_retries` 5, `handshake_retries` 2, `max_duration`
600 s, file name `boot/boot.wim`, mode `octet`.

Regenerate (from `fuzz/`; function `window_seeds`):

```sh
cargo run --example gen_seeds_m3 -- corpus
```

| Seed | Content |
|------|---------|
| `wu14-window-8-complete.bin` | 5000 octets, `blksize=512`, `windowsize=8`, `tsize=0`; one run op to completion |
| `wu14-window-wrap-zero.bin` | 600,000 octets at `blksize=8` (75,001 blocks), `windowsize=64`, wrap to 0; run to completion across one wrap |
| `wu14-window-wrap-one.bin` | the same, wrap to 1 |
| `wu14-window-wrap-off-refused.bin` | the same with wraparound off (refused, too many blocks) |
| `wu14-window-partial-acks.bin` | 3000 octets, `blksize=64`, `windowsize=16`: OACK, drain, partial ACK, timer resend, stale ACK, completion steps |
| `wu14-window-lockstep.bin` | 2000 octets, no options, window maximum 1 |
| `wu14-window-retry-cap.bin` | first window then seven timer expiries (retry cap) |
| `wu14-window-client-error.bin` | first window then client ERROR 8 |
| `wu14-window-exact-multiple.bin` | 4096 octets at 512 (empty final block) |
| `wu14-window-raw-ack.bin` | 1000 octets: raw ACKs 0, 1 and 65535 |
