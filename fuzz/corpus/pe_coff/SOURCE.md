# Seed origin: `pe_coff`

Every seed here is generated by our own code:
`usgp_proto::pe_coff::sample::header` and `sample::uefi_x64` (file heads
built from the PE/COFF field list of `specs/standards/winpe.md` §10), plus
two edits made in the generator. None comes from a boot program, Windows
media or any other binary (fuzz/README.md, seed origin rule).

Regenerate (from `fuzz/`; function `pe_seeds`):

```sh
cargo run --example gen_seeds_m3 -- corpus
```

| Seed | Content |
|------|---------|
| `wu14-pe-uefi-x64.bin` | x64, PE32+, subsystem 10 (accepted) |
| `wu14-pe-x86.bin` | machine `0x014C` |
| `wu14-pe-arm64.bin` | machine `0xAA64` |
| `wu14-pe-pe32.bin` | magic `0x10B` |
| `wu14-pe-subsystem-11.bin` | subsystem 11 |
| `wu14-pe-truncated.bin` | the first `0x90` octets of the accepted head |
| `wu14-pe-pointer-past-end.bin` | signature pointer `0xFFFFFFF0` |
