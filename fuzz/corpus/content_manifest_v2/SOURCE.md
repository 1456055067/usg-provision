# Seed origin: `content_manifest_v2`

Every seed here is generated by our own code in `examples/gen_seeds_m4.rs`
(function `content_v2_seeds`): `ContentManifestV2` values built in the generator
(filler digests) and written with `to_payload`, or `serde_json` for the refused
one. None comes from captured traffic, a log, an image, a driver package, tool
output or any deployment of another product (fuzz/README.md, seed origin rule).

Regenerate (from `fuzz/`):

```sh
cargo run --example gen_seeds_m4 -- corpus
```

| Seed | Content |
|------|---------|
| `wu12-driver-archive.bin` | driver archive, 5 octets, two INFs |
| `wu12-agent-package-3-chunks.bin` | agent package, three chunks |
| `wu12-agent-with-inf.bin` | agent package listing an INF (refused) |
