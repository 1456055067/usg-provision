# Seed origin: `inflate_diff`

Every seed here is generated by our own code in `examples/gen_seeds_m4.rs`
(function `inflate_seeds`): raw DEFLATE streams from `usgp-wincfg` testkit
(`deflate_stored`, `deflate_fixed`) and `miniz_oxide`'s encoder, each checked
with `inflate_slice`; text written in the generator. One stream is two octets
hand-built from RFC 1951 §3.2.3 (reserved block type). None comes from captured
traffic, a log, an image, a driver package, tool output or any deployment of
another product (fuzz/README.md, seed origin rule).

Octet 0 selects the mode (see `fuzz_targets/inflate_diff.rs`).

Regenerate (from `fuzz/`):

```sh
cargo run --example gen_seeds_m4 -- corpus
```

| Seed | Content |
|------|---------|
| `wu12-stored.bin` | 0: stored block |
| `wu12-fixed-match.bin` | 0: fixed Huffman, a length-258 match |
| `wu12-dynamic.bin` | 0: dynamic Huffman (level 9) |
| `wu12-reserved-type.bin` | 0: block type 3 (refused) |
| `wu12-roundtrip-level6.bin` | 1: level 6, text |
| `wu12-roundtrip-level0.bin` | 1: level 0, `short` |
