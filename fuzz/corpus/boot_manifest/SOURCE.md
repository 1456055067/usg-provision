# Seed origin: `boot_manifest`

Every seed here is generated by our own code: `usgp-proto`
`BootManifest::new` and `with_pe_kit` with entries and digests made up in
the generator, written with `BootManifest::to_toml`. None comes from a
relay deployment, Windows media or any deployment of another product
(fuzz/README.md, seed origin rule).

Regenerate (from `fuzz/`; function `manifest_seeds`):

```sh
cargo run --example gen_seeds_m3 -- corpus
```

| Seed | Content |
|------|---------|
| `wu14-manifest-plain.bin` | one file, no `[pe_kit]` |
| `wu14-manifest-pe-kit.bin` | five files and a `[pe_kit]` naming them, one font |
| `wu14-manifest-pe-kit-digest-mismatch.bin` | the same with `pe_content_sha256` not the WIM's digest |
| `wu14-manifest-pe-kit-unpublished-font.bin` | the same with a font that is not a listed file |
