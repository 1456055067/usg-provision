# Seed origin: `inf_version`

Every seed here is generated by our own code in `examples/gen_seeds_m4.rs`
(function `inf_seeds`): INF text written in the generator from the `[Version]`
rule of plan section 1.5 (`Signature`, `CatalogFile`); one copy re-encoded as
BOM-led UTF-16LE. The target places it as `pkg/x.inf` next to `pkg/x.cat` and
`pkg/y.cat`. None comes from captured traffic, a log, an image, a driver
package, tool output or any deployment of another product (fuzz/README.md, seed
origin rule).

Regenerate (from `fuzz/`):

```sh
cargo run --example gen_seeds_m4 -- corpus
```

| Seed | Content |
|------|---------|
| `wu12-windows-nt.bin` | `$Windows NT$`, `CatalogFile = x.cat`, CRLF |
| `wu12-utf16.bin` | the same as UTF-16LE |
| `wu12-chicago-decorated.bin` | `$CHICAGO$`, decorated and plain catalog keys |
| `wu12-missing-catalog.bin` | catalog `z.cat` not present |
| `wu12-no-version.bin` | keys outside `[Version]` |
| `wu12-quoted-semicolon.bin` | `;` inside a quoted value |
