# 0007: Operator Authentication by Mutual TLS (PIV/CAC)

- Status: Accepted (owner, 2026-10-26)
- Date: 2026-10-26
- Decider: project owner
- Resolves: roadmap decision D-6

## Decision

The M2 operator API authenticates operators with TLS client certificates
(PIV/CAC or agency-issued), validated per RFC 5280 against configured trust
anchors through `usgp-crypto` (decision 0001), over TLS configured per NIST
SP 800-52 Rev 2. Each certificate maps to one operator identity; there are
no shared or anonymous operator accounts. Revocation checking and the
identity mapping are designed in the M2 plan. OIDC may be added later
behind the same identity model.

## Consequences

- Unauthenticated requests are refused (401) and audited (decision 0010).
- Tests use certificates generated by the test harness, never real PIV data.
