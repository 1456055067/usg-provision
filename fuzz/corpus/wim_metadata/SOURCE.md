# Seed origin: `wim_metadata`

Every seed here is generated by our own code: the `usgp-image` test tree
encoder (`TreeSpec::encode`, feature `testkit`). None comes from a
third-party WIM file or tool, from Windows media, or from any deployment
of another product (fuzz/README.md, seed origin rule; decision 0006
items 1-3). The DISM-made samples are **not** used as seeds.

Each seed is a decoded metadata resource (the whole input of the target).

Regenerate (from the repository root):

```sh
cargo run -p usgp-image --features testkit --example gen_fuzz_seeds -- <scratch>
cp <scratch>/wim_metadata/*.bin fuzz/corpus/wim_metadata/
(cd fuzz && cargo run --example gen_seeds_m3 -- corpus)
```

| Seed | Generator | Content |
|------|-----------|---------|
| `small.bin` | `crates/usgp-image/examples/gen_fuzz_seeds.rs` | short name, named stream, two hard-link names, a relative symbolic link |
| `sample.bin` | same | `TreeSpec::sample()` (every applied feature) |
| `wu14-links.bin` | `fuzz/examples/gen_seeds_m3.rs` `metadata_seeds` | rewritten absolute link and junction (+92 = 0), a copied junction, a relative link |
| `wu14-deep.bin` | same | five nested directories and a file with a short name |
| `wu14-empty-root.bin` | same | the root alone |
