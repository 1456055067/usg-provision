# Seed origin: `wim_apply_plan`

Every seed here is generated by our own code: the `usgp-image` test WIM
builder (`WimBuilder::tree_image`, feature `testkit`) and its link-data
helpers (`abs_link_data`, `rel_link_data`). None comes from a
third-party WIM file or tool, from Windows media, or from any deployment
of another product (fuzz/README.md, seed origin rule; decision 0006
item 4). The DISM-made samples are **not** used as seeds.

A seed that starts with the WIM signature is a whole file (image 1, root
`W:\`); any other starts with a selector octet (see
`fuzz_targets/wim_apply_plan.rs`).

Regenerate (from the repository root):

```sh
cargo run -p usgp-image --features testkit --example gen_fuzz_seeds -- <scratch>
cp <scratch>/wim_apply_plan/*.bin fuzz/corpus/wim_apply_plan/
(cd fuzz && cargo run --example gen_seeds_m3 -- corpus)
```
