# Seed origin: `api_json`

Every seed here is generated by our own code: `usgp-proto` request,
manifest and envelope types serialized with `serde_json` (or the types'
own `to_payload` / `to_json`), plus a few hand-written values from the
open standards named below. None comes from captured traffic, logs or any
deployment of another product (fuzz/README.md, seed origin rule).

Octet 0 selects the parser (see `fuzz_targets/api_json.rs`); the rest is
the input. The envelope signature is 103 octets of `0x30`, not a real
signature: the target only parses.

Regenerate (from `fuzz/`): `cargo run --example gen_seeds -- corpus`
(function `api_seeds`).
