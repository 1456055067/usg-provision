# Seed origin: `postsetup_msgs`

Every seed here is generated by our own code in `examples/gen_seeds_m4.rs`
(function `postsetup_seeds`): `usgp-proto` types serialized with `serde_json`,
or JSON text written in the generator in the shapes of the `usgp-proto` unit
tests, checked with `parse_request` and `MAX_DEVICE_JSON_BYTES` (or
`PostSetupConfigV1::to_json`). Keys, nonces, ciphertext and signatures are fixed
filler octets, the token is 43 `A`s and the PEM blocks hold `AAAA`; none is a
real secret or key. None comes from captured traffic, a log, an image, a driver
package, tool output or any deployment of another product (fuzz/README.md, seed
origin rule).

Octet 0 selects the body type (see `fuzz_targets/postsetup_msgs.rs`).

Regenerate (from `fuzz/`):

```sh
cargo run --example gen_seeds_m4 -- corpus
```
