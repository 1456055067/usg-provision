# Seed origin: `dhcp_packet`

Every seed here is generated by our own code from
`usgp_dhcp::craft::RequestBuilder` (a client-side encoder written from the
open-standard summaries in `specs/standards/`). None comes from packet
captures, logs, images or any deployment of another product
(fuzz/README.md, seed origin rule).

Regenerate (from the repository root):

```sh
cargo run -p usgp-dhcp --example gen_fuzz_seeds -- fuzz/corpus/dhcp_packet
(cd fuzz && cargo run --example gen_seeds -- corpus)
```
