# NIST SP 800-53 Rev 5 control mapping

Status as of milestone M1 (network boot, 2026-10-26). Statuses are backed by
code and passing gates only; nothing here is a claim of control satisfaction
for the ATO. Values: Not implemented, Planned, Partial, Implemented.

M1 evidence limits that apply to every row below:

- Tests ran on a macOS development host. The relay's socket layer
  (`SO_BINDTODEVICE`) runs only on Linux, so every relay behaviour is
  evidenced in-process with in-memory sockets.
- Boot smoke scenarios S1 to S8 (live network, firmware, Secure Boot) are
  NOT RUN (POAM-17). No control below rests on them.
- QA's final pass (2026-10-26) confirmed every fix-round 2 and 3 test by
  name. The one Linux-only test (`config_rejected_carries_host_node_name`)
  is NOT RUN.
- Test names are listed in `docs/compliance/TEST_EVIDENCE.md` and
  `docs/compliance/SPEC_TRACEABILITY.md`.
